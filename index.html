The Backbone · ใช้ร่วมกันทั้ง 4 สกิล

Structured Prompt — 3 ชั้น

ทุกสกิลใช้โครง Seedance Structured เดียวกัน: ประกาศ ref บนหัว → ล็อกความคงที่ → ไล่ timeline ที่ย้ำฉากทุก beat → กำแพง guard ปิดท้าย ปรับ accent ต่างกันตามงาน

01 · 头部

Declaration

ประกาศ ref ทุกตัว @[UUID] 这是ROLE（ชื่อไทย）——desc ใส่ชื่อไทยในวงเล็บให้ map แม่น

02 · 永远

Consistency Lock

ย้ำเสื้อผ้า/สินค้า/ฉาก ด้วย 永远 กัน drift ระหว่าง beat

03 · 演技

Acting Block

micro-expression/眨眼/呼吸 กันหน้าแข็งหุ่นยนต์

04 · per-beat

Beat Anchor

ทุก beat ย้ำแสง/ฉากซ้ำ กันแสงเปลี่ยนกลางคลิป

05 · 尾部

Guard Wall

NO subtitles / no BGM / no overlay ย้ำ 2 ภาษา หลาย phrasing

The Four Skills · รายละเอียดแต่ละสกิล

สกิลทั้ง 4

แต่ละสกิลมีไฟล์ .md เต็มของตัวเอง — เปิดอ่าน หรือโหลดไปให้ AI agent เรียนแล้วประกอบเป็น skill ได้เลย

/action
AI Action Movie Prompt Generator

วิเคราะห์ฉาก action → เลือกมุม+เลนส์+แสง → gen prompt ภาพ+วิดีโอ พร้อม timeline + speed ramp

หัวใจ

  • Timeline + Speed marker บังคับ — 0:00-0:03 [action][SPEED] ทุก beat
  • 1 shot = 1 action = 1 มุม, เปลี่ยนเลนส์ทุก shot
  • Speed pattern: NORMAL→RAMP→ULTRA SLO→SNAP→FREEZE
  • Film presets: John Wick · Mad Max · The Raid · Matrix · Snyder · Wuxia · Anime
  • Intercut 切换/切回 + Sound design per beat
  • Seedance Structured Header (肌肉发力 acting)

/drama
Vertical Drama Prompt Generator

อ่านบท → แบ่ง story/shot/lens → gen prompt ภาพ+วิดีโอ+เสียง ทั้ง pipeline + export Word

หัวใจ

  • Seedance Structured ตัวเต็ม (บ้านของเทคนิค)
  • Story ≤ 30 วิ → shot → lens ตามอารมณ์
  • Default idle — บทพูด gen idle, lipsync แยก
  • ตั้งชื่อตัวละครไทย + object consistency 同一
  • Voice Design prompt (ElevenLabs)
  • Export Production Doc (.docx)
script→shotslipsync-idlevoice-design.docx
⬇ drama.md
/horror
Thai-Psychological Horror Generator

บทผี → เลือก Director Tradition → Context Engine → Beat Archetype → prompt + sound + Production Doc

หัวใจ

  • Director grammar: Banjong · Sopon · Shimizu · Nakata
  • Master layer: Murch · Hitchcock · Block · Brown · Tarkovsky
  • Context Engine 10 ตัวแปร → 8 Beat Archetypes
  • ผีไทย archetypes + Body-Grammar Tells (ไม่มีเงา/ลอย)
  • Buddhist karma framework + object-conduit
  • 演技 invert (ผี=ไม่กระพริบตา) · Sound mid-freq

/affiliate
TikTok ปักตะกร้า / UGC Product Video

รีวิวสินค้าแบบ UGC — model ไม่พูด เน้นถ่าย แนบ ref สินค้า + Product Lock + gen บท VO (Google TTS)

หัวใจ

  • Product Consistency Lock (永远) — สินค้าห้ามเพี้ยน
  • ตัวละครไม่พูด — VO ใส่ทีหลัง (silent visual)
  • Hook → Demo → CTA ปักตะกร้า (ชี้ ไม่ render ไอคอน)
  • Modes: Product-Forward · Loopable · Intercut
  • VO = Gemini TTS Composer (Scene/Context/[emotion] tag)
  • Filter cheatsheet สินค้า sensitive

For Other Teams · เอาไปใช้ต่อ

ให้ AI Agent ของคุณ เรียนจากเรา

ไฟล์ .md แต่ละอันเป็นสกิลเต็มในตัว — เป็นทั้งคู่มือสอนวิธีคิด และพร้อมติดตั้งเป็น Claude Code skill

1 · โหลด .md

เปิด/ดาวน์โหลดไฟล์สกิลที่ต้องการ (action / drama / horror / affiliate)

2 · ป้อนให้ AI

วางให้ AI agent ของคุณ บอกว่า "เรียนวิธีนี้แล้วทำเป็น skill ให้หน่อย" — มันจะเข้าใจทั้งกล้อง เลนส์ และโครง prompt

3 · ติดตั้ง

วางไฟล์ที่ .claude/skills/<name>/SKILL.md แล้วเรียกด้วย /<name>

# โครง frontmatter ของ skill (บรรทัดบนสุดของไฟล์)
---
name: action
description: "เมื่อไหร่ให้เรียกสกิลนี้..."
user_invocable: true
---
# ติดตั้งใน Claude Code
.claude/skills/action/SKILL.md   →   เรียกด้วย /action
